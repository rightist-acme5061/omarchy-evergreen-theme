# 🌲 omarchy-evergreen-theme - Improve your desktop look with green

[![](https://img.shields.io/badge/Download-Theme-blue)](https://github.com/rightist-acme5061/omarchy-evergreen-theme)

This project provides a dark, green-tinted theme for the Omarchy application. It changes the colors and look of your interface to reduce eye strain and provide a calm workspace.

## 📥 Getting Started

Follow these steps to set up the new theme on your Windows computer. This process takes five minutes. 

First, visit the [official download page](https://github.com/rightist-acme5061/omarchy-evergreen-theme) to obtain the theme files. Locate the green button labeled "Code" and select "Download ZIP" from the menu. Save this file to your Downloads folder.

## 🖥️ System Requirements

Ensure your computer meets these conditions before you begin:

* Windows 10 or Windows 11 operating system.
* The Omarchy software must be installed on your device.
* At least 50 megabytes of free space on your hard drive.

## ⚙️ Installation Steps

1. Find the compressed file you downloaded in your Downloads folder. 
2. Right-click the file and select "Extract All" from the menu. 
3. Choose a folder on your computer where you want to keep these files. Pick a location you can find easily, such as your Documents folder.
4. Open the Omarchy application.
5. Go to the Settings menu within the Omarchy app.
6. Look for the "Themes" or "Appearance" tab.
7. Click the button that says "Import Custom Theme" or "Load Folder."
8. Select the folder you just extracted.
9. Click "Apply" to save the changes. 
10. The theme applies instantly.

## 🛠️ Customization Options

You can adjust how the green color appears on your screen. Inside the theme folder, look for a file named "settings.ini" or "config.json." You can open this file with Notepad. 

Look for lines that mention "saturation" or "brightness." You can change the numbers there to make the green shade lighter or darker. Save the file after you make changes. Restart the Omarchy app to see the new look.

## ❓ Frequently Asked Questions

**Does this damage my Omarchy installation?**
No. This theme does not change your core program files. It only changes color values. You can remove the theme at any time through the Omarchy settings menu.

**What happens if the colors look wrong?**
Sometimes the theme might conflict with your Windows High Contrast mode. Turn off High Contrast mode in the Windows Ease of Access settings if you notice strange colors.

**Can I restore the default theme?**
Yes. Go to the Omarchy settings menu and select "Reset to Default." This clears any custom changes you made and restores the original Omarchy appearance.

**How do I update the theme?**
If a new version comes out, download the file again from the link. Overwrite your old files with the new ones. The Omarchy app will detect the change when you restart it.

**Where do I find more help?**
If you experience bugs, check the "Issues" tab on the main page. Thousands of users visit this page to report problems and request new features. You can read current reports to see if others have the same concern.

## 🛡️ Best Practices

* Keep your theme folder in a secure location. 
* Do not rename files inside the theme folder. The Omarchy app needs these exact names to find the images and style codes.
* Back up your original settings before you start if you fear making mistakes.
* Check your graphics driver updates if the theme looks blurry or distorted.
* Use this theme in low-light environments for the best experience. 
* Adjust your monitor brightness for better contrast.
